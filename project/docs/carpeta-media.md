Las carpetas para guardar imágenes en backend/media/images son:

| Carpeta de Destino        | Representación de la Imagen                                                 |
| :------------------------ | :-------------------------------------------------------------------------- |
| courses                   | Portadas de cursos y material educativo.                                    |
| jobs                      | Logos de empresas y banners de ofertas laborales.                           |
| entrepreneurships         | Imágenes de emprendimientos periodísticos.                                  |
| news-articles             | Imágenes destacadas de noticias (principales y secundarias).                |
| press-releases            | Fotos que acompañan los comunicados de prensa.                              |
| ngo-spotlights            | Logos e imágenes de ONGs destacadas.                                        |
| freelance-services        | Imágenes promocionales de servicios independientes.                         |
| community-ads             | Creativos para anuncios de la comunidad.                                    |
| premium-sponsors          | Logos de alta resolución de patrocinadores premium.                         |
| promo-videos              | Miniaturas (thumbnails) de videos promocionales.                            |
| community-posts           | Imágenes subidas por usuarios en el muro o foro.                            |
| photojournalism-posts     | Fotografías periodísticas de alta calidad (galería).                        |
| specialists               | Fotos de perfil de expertos y especialistas.                                |
| shareable-photos          | Imágenes optimizadas para compartir en redes sociales.                      |
| resources                 | Infografías, portadas de PDF o recursos descargables.                       |
| funding-opportunities     | Imágenes de convocatorias a fondos o becas.                                 |
| events                    | Afiches y fotos de eventos o seminarios.                                    |
| legal-topics              | Iconografía o imágenes para secciones legales/normativas.                   |
| hero-headings             | Imágenes de gran tamaño para el encabezado (Hero) de la Home.               |
| short-collaborations      | Avatares o fotos de solicitudes de ayuda rápida.                            |
| entrepreneurship-tips     | Miniaturas de videos o fotos para consejos técnicos.                        |
| sponsored-ads             | Banners de publicidad pagada (externa).                                     |
| special-ads               | Imágenes para anuncios destacados o temporales.                             |
| site-stats                | Iconos para visualización de datos y estadísticas.                          |
| partner-logos             | Logos de instituciones aliadas.                                             |
| talent-profiles           | Fotos de portafolio para perfiles de periodistas.                           |
| app-configs               | Logos del sitio, favicon y elementos de identidad visual.                   |
| users                     | Fotos de perfil y avatares de los usuarios registrados.                     |
